# Security Policy

## Supported Versions

Security fixes are provided for the latest `main` branch and the latest release tag.

## Reporting a Vulnerability

Please report vulnerabilities privately to: `security@aiden.local`

Include:

- Affected version/tag
- Reproduction steps
- Expected vs actual behavior
- Impact assessment

We will acknowledge reports within 5 business days and provide status updates during triage/remediation.

Please do not open public issues for undisclosed security vulnerabilities.

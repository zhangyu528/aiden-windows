# 功能规格-FSD

## 1. 文档定位

本文档定义用户可见功能行为与可验证规则，不展开底层实现细节。

## 2. 功能范围

覆盖模块：
- 主面板指标展示
- 多 CLI 页签切换与可用性控制
- 启动引导与 CLI 开通管理
- 自动刷新与手动刷新
- 启动中/启动失败状态页

## 3. 主面板功能规则

### 3.1 展示字段
- Input Tokens
- Output Tokens
- Current User Email
- User Active
- Cost USD
- Context（值 + %）
- Status（Online/Offline）

### 3.2 触发与刷新
- 自动刷新按配置周期执行。
- 用户可手动触发刷新。

### 3.3 字段降级显示
- 无可识别用户：`Current User Email=Unknown`
- 用户相关指标不可用：显示 `N/A`
- 无成本数据：显示 `0`（或 UI 占位规则）

## 4. 多 CLI 页签规则

### 4.1 可用性判定
- 条件：CLI 已安装且已开通。

### 4.2 切换行为
- 只允许切换到可用页签。
- 不可用页签保持禁用。

### 4.3 失效回退
- 若当前页签变为不可用，自动回退到首个可用页签。

## 5. 启动与异常状态

- 启动阶段显示 loading 状态。
- 关键依赖不可用时显示 startup error，并给出用户可执行操作（重试/退出等）。

## 6. 后台运行规格

- UI 退出不影响后台采集链路。
- RuntimeAgent 持续守护 VM/Collector，异常时尝试恢复。

## 7. 可测试验收条款

- 页面字段与刷新行为符合第 3 节。
- 页签可用性、禁用与回退符合第 4 节。
- 启动异常可被用户识别并处理。
- UI 退出后后台采集持续。
